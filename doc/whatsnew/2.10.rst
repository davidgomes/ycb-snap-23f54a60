 What's New in Pylint 2.10
***************************

:Release: 2.10
:Date: TBA

Summary -- Release highlights
=============================


New checkers
============

* Added ``unspecified-encoding``: Emitted when open() is called without specifying an encoding

  Closes #3826


Other Changes
=============


* Performance of the Similarity checker has been improved.

* The default PYLINTHOME is now the user cache directory following the XDG Base Directory
  Specification on Linux (usually ``~/.cache/pylint``) and the platform conventions elsewhere,
  instead of ``~/.pylint.d``. A message is printed if the obsolete ``~/.pylint.d`` still exists.

  Closes #3878

* Added ``time.clock`` to deprecated functions/methods for python 3.3
