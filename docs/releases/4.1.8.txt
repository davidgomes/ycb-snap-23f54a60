==========================
Django 4.1.8 release notes
==========================

*Expected April 3, 2023*

Django 4.1.8 fixes several bugs in 4.1.7.

Bugfixes
========

* Fixed a bug in Django 4.1 where :setting:`SECRET_KEY_FALLBACKS` weren't used
  to verify session authentication hashes, logging out all users after a
  secret key rotation (:ticket:`34384`).
