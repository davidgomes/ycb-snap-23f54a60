==========================
Django 3.1.5 release notes
==========================

*Expected January 4, 2021*

Django 3.1.5 fixes several bugs in 3.1.4.

Bugfixes
========

* Fixed ``__isnull=True`` lookup on key transforms for
  :class:`~django.db.models.JSONField` with Oracle and SQLite
  (:ticket:`32252`).

* Fixed a bug in Django 3.1 that caused the middleware chain to be
  incorrectly adapted when a middleware raised
  :exc:`~django.core.exceptions.MiddlewareNotUsed` in an ASGI context
  (:ticket:`32299`).
