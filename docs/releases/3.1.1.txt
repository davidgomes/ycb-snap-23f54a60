==========================
Django 3.1.1 release notes
==========================

*Expected September 1, 2020*

Django 3.1.1 fixes several bugs in 3.1.

Bugfixes
========

* Fixed wrapping of translated action labels in the admin's navigation sidebar
  for East Asian languages (:ticket:`31853`).

* Fixed wrapping of long model names in the admin's navigation sidebar
  (:ticket:`31854`).

* Fixed session data written by Django 3.1 being unreadable by pre-3.1
  instances when ``DEFAULT_HASHING_ALGORITHM`` is ``'sha1'``. Sessions are
  encoded with the legacy format in that case.
